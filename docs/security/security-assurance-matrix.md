automated checks and an internal white-hat assessment. It is not an independent
penetration test.

OWASP Top 10 is used as a completeness cross-check: access control (setup,
sessions, restore), cryptographic failures (MFA key and backup), injection
(provider/subprocess/path), insecure design (root and management VLAN),
misconfiguration (proxy/systemd), vulnerable components (audit/Dependabot),
authentication failures, integrity failures (backup/upgrade/supply chain),
logging failures, and SSRF-relevant webhook/provider boundaries.

## Release interpretation

`Resolved` means the documented control and automated regression exist.
`Accepted` requires an explicit deployment assumption or operator control.
`Release blocker until LXC` must remain open until the real Debian 13 appliance
evidence is recorded in pull request #34. `Later external review` is not evidence
of independent assurance and must not be described as such.
