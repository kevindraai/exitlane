# ExitLane 0.2.0-beta.4 release notes

## Summary

Beta.4 is a UX and documentation polish release. It connects ExitLane to the N/L Foundry design
foundation, makes the existing administrator guides available inside the WebUI, and improves
consistency and accessibility without expanding the VPN appliance feature set.

## UX and design system

- ExitLane is classified as a technical N/L Foundry product and adopts the Cobalt / Slate theme,
  selected for its operations and professional-interface use cases.
- A thin semantic mapping now covers background, surfaces, borders, text, primary interactions,
  focus and status communication in independently designed light and dark modes.
- Page heading scale, primary-action contrast and shared focus treatment are more consistent.
- Optional individual Diagnostics tools now use progressive disclosure so the primary connection
  flow remains visually dominant.
- Missing local Diagnostics icons no longer fall back to a generic shield.

## Integrated documentation

- Authenticated administrators can open **Help & documentation** from the main navigation.
- Existing repository Markdown remains the single content source; there is no duplicated help
  authoring system.
- User-facing guides are grouped into Getting started, VPN, WireGuard, Diagnostics, Security and
  Appliance management.
- Diagnostics, WireGuard, reverse proxy, authentication, MFA, backup/restore, upgrade/recovery and
  killswitch surfaces link directly to their relevant guide.
- GitHub remains available as a supplementary source link, not the primary help path.

## Accessibility

- Visible focus treatment now includes selects, textareas and programmatically focusable content.
- Contextual help uses descriptive link text, and documentation navigation preserves semantic
  headings, lists, code blocks and tables.
- Status remains represented with text and icons in addition to color.
- Mobile layouts stack documentation cards, page actions and contextual links without requiring
  horizontal scrolling.

## Bug fixes

- Fixed self-referential dark-mode values for code backgrounds, progress tracks and toast
  backgrounds.
- Primary button text now uses the selected theme's explicit contrast role.

## Internal and refactor changes

- The documentation API exposes only a fixed allowlisted catalog. Markdown is projected into typed
  blocks; raw HTML is never trusted or returned, and URL schemes are allowlisted.
- The browser constructs document elements with `textContent` and does not introduce an HTML
  parsing sink, external script or CDN dependency.
- Regression coverage verifies the catalog, authentication boundary, unsafe-link rejection,
  no-HTML rendering contract, contextual links, theme mapping and dark-mode token fix.

## Upgrade notes and limitations

Upgrade transaction, rollback, database, secret key, users, sessions, MFA, WireGuard and settings
preservation use the existing beta lifecycle. Release publication still requires the complete
automated gates plus Debian appliance upgrade, rollback/recovery and browser QA evidence against
the exact final `origin/main` release SHA.

The current local candidate evidence and remaining release blockers are recorded in the
[beta.4 validation record](../security/beta4-validation.md).

ExitLane remains beta software for a trusted management network and must not be exposed directly
to the public Internet.
