# ExitLane 1.0.0

Stable v1 retains the accepted candidate's scope. Native Debian 13 amd64 supports NordVPN,
Mullvad, PIA and imported Proton WireGuard. Docker v1 supports Mullvad, PIA and imported Proton
on Linux amd64, rootful Docker Engine >=28 and Compose v2, NET_ADMIN/TUN, read-only root and
one durable state volume. NordVPN is unavailable inside Docker; its separate gateway is NO-GO.
Live commercial PIA/Proton interoperability remains unqualified and #72 is claim-specific.

Follow the [Docker Quick Start](../docker-deployment.md#quick-start) for versioned files,
explicit trusted-LAN binds, image digest verification, preflight, first-run setup and lifecycle.
The official versioned image is `ghcr.io/kevindraai/exitlane:v1.0.0`; no Docker latest alias is defined.

## Security and upgrade

Full scanner findings and original severities remain intact. Actionable findings block release;
reviewed exact unfixed Debian identities receive applicability/mitigation dispositions as residual
platform risks under [SECURITY](../../SECURITY.md). The published release links final native/image
inventories and decision reports; historical scans retain their original scope.

Create, verify and export an encrypted backup before upgrading from rc.4/v1 RC. Use
[native upgrade/recovery](../upgrade-and-recovery.md) or the separate
[Docker upgrade/rollback path](../docker-deployment.md#upgrade-and-rollback). Preserve the previous
exact compatible source/image, deployment configuration and backup. Schema compatibility is not
inferred from a tag. Stable promotes the accepted RC without unrelated functionality.
