# ExitLane 1.0.0-rc.1

This candidate fixes the complete v1 delivery contract. Native Debian 13 amd64 supports NordVPN,
Mullvad, PIA and imported Proton WireGuard. Docker supports the three direct providers under
the [operator contract](../docker-deployment.md), with no plaintext fallback. NordVPN remains
native-only; the separate gateway approach is NO-GO. Live PIA/Proton is unqualified.

## Qualification and publication

This document prepares the candidate; it does not assert publication or successful qualification.
Record exact tag/source/package/checksums, independent review, full CI/security, rc.4 upgrade,
installer/lifecycle/recovery and published-artifact verification before declaring it qualified.
The rc.4 public Proxmox ladder must already have passed before this candidate is prepared.

Stable source and official `ghcr.io/kevindraai/exitlane:v1.0.0` image publication follow qualification.
Final image content/TLS/runtime/state/dataplane qualification, D6 delta reconciliation, digest
binding, SBOM/provenance and anonymous pull are mandatory; no image availability claim is made here.
Reviewed exact unfixed Debian findings follow [SECURITY](../../SECURITY.md), retaining full scans
and applicability/mitigation evidence. Available fixes and concrete security defects remain blockers.

## Upgrade and recovery

Export and verify an encrypted backup before upgrading from qualified rc.4. Follow
[native upgrade/recovery](../upgrade-and-recovery.md) or the separate
[Docker lifecycle path](../docker-deployment.md#upgrade-and-rollback). Keep the previous exact
source/image and compatible backup; state/schema compatibility is not inferred from a tag.
