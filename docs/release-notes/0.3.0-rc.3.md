# ExitLane 0.3.0-rc.3

This patched post-Daybreak release candidate includes the security remediations in
PRs #81–#84. Runtime and tag versions are `0.3.0-rc.3` and `v0.3.0-rc.3`; the
Python package version is `0.3.0rc3`.

## Changes since rc.2

- Harden WireGuard setup input and configuration ownership boundaries.
- Validate restored WireGuard hooks before any privileged lifecycle mutation.
- Bound streamed HTTP request bodies, provider responses and archive expansion.
- Validate provider-controlled values and diagnostic destinations.
- Add direct PIA and imported Proton WireGuard profile providers.
- Apply Tuned.pixel identity, local Inter assets and appliance-focused theming.
- Add a repository-owned Proxmox helper with preview and deterministic safety tests.
- Record the internal Daybreak Blue-assisted defensive assessment and its evidence limits.

## Installation and upgrade

The supported baseline is Debian 13 amd64, including the qualified privileged LXC.
Keep management on a trusted network. Docker remains development-only and is
**not yet suitable** as a supported network appliance.

```bash
git clone --branch v0.3.0-rc.3 --depth 1 https://github.com/kevindraai/exitlane.git
cd exitlane
sudo ./installer/install-debian.sh
```

Before upgrading, create and verify an encrypted backup, retain console access,
and follow [Upgrade and recovery](../upgrade-and-recovery.md). Run the new
installer outside `/opt/exitlane`; verify version, login, configuration and traffic
protection afterwards.

## Evidence boundaries

Live PIA and Proton account connectivity remains unproven; synthetic provider
evidence is recorded separately. The repository PVE helper's end-to-end creation
flow remains unqualified unless explicitly demonstrated using that helper.
Creating a qualification guest through the organization runner does not qualify
that separate helper. Protected IPv6 remains blocked.

The [Daybreak report](../security/daybreak-blue-assessment-2026-09-30.md) records
an internal defensive assessment, not an independent external penetration test.
Release qualification must identify the final merged-main SHA, fresh validation
results and downloadable artifact checksums before publication.
