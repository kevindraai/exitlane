# ExitLane 0.3.0-rc.2

ExitLane 0.3.0-rc.2 improves provider setup and administrator documentation. It includes the
NordVPN wizard and Help fixes from [PR #70](https://github.com/kevindraai/exitlane/pull/70).

The tag and runtime version are `v0.3.0-rc.2` and `0.3.0-rc.2`; the Python package version is
`0.3.0rc2`. This remains a release candidate. At the maintainer's explicit request, GitHub marks
it **Latest**, making it available through GitHub's latest-release link. That label does not expand
the supported scope.

## Changes since rc.1

- Provider selection uses labeled checkboxes. Separate, clearly styled configuration tabs support
  keyboard navigation and show which provider is being configured.
- The NordVPN installation action reappears after switching from Mullvad. Delayed status and
  installation responses cannot replace the currently viewed provider's state.
- Rejected provider selections recover the confirmed state. Skipping applies to the viewed
  provider, and navigation remains available when no providers are selected.
- The new [NordVPN guide](../nordvpn.md) covers installation, token sign-in, session replacement,
  routing, troubleshooting and recovery. Both provider pages link to their integrated Help guide.
- Mobile Help wraps long content and breadcrumbs within the screen width.
- The development Ruff dependency advances from 0.16.3 to 0.16.8.

The [rc.1 notes](0.3.0-rc.1.md) describe the underlying direct Mullvad integration, traffic
protection and recovery features retained in this candidate.

## Installation and upgrade

The supported baseline remains **Debian 13, amd64**, on a dedicated appliance or the qualified
privileged Proxmox LXC. Keep management access on a trusted network.

For a new installation, use the published tag:

```bash
git clone --branch v0.3.0-rc.2 --depth 1 https://github.com/kevindraai/exitlane.git
cd exitlane
sudo ./installer/install-debian.sh
```

Existing rc.1 or v0.2.0 appliances should follow [Upgrade and recovery](../upgrade-and-recovery.md):
create and verify an encrypted backup, retain console access, schedule a traffic interruption,
and run the new tag's installer from outside `/opt/exitlane`. Verify the reported version, login,
saved configuration, provider status and routed client traffic afterwards.

## Scope and qualification

Mullvad remains IPv4-only, protected IPv6 is blocked, and only one commercial provider can be
active. Docker, unprivileged LXC, other Debian releases and other architectures remain unsupported.
The trusted management network and existing [security policy](../../SECURITY.md) still apply.
No new security boundary is introduced by these UI, documentation and version changes.

PR #70 records the native Playwright qualification: provider switching, keyboard/mobile behavior,
rejected and delayed responses, exactly one real NordVPN installation, installation recovery after
reload, and both integrated provider guides. That test did not submit VPN credentials or run a
Speedtest. The published release qualification must additionally identify the exact final main SHA,
release gates and artifact checksums required by the [release checklist](../release-checklist.md).
